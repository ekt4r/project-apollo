# Local data

- `raw/deam/MEMD_audio/`: original DEAM MP3 files.
- `raw/deam/metadata/`: original metadata CSV files.
- `processed/`: derived audio and fingerprint indexes.
- `queries/`: generated query clips and their ground truth.

Keep original files unchanged. Audio, archives, metadata, and generated artifacts are excluded from Git.

DEAM source: https://cvml.unige.ch/databases/DEAM/

For excerpt recordings, localization timestamps are relative to the indexed file, not necessarily to the full song.
